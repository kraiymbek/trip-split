# Trip Split

PWA для общих расходов в поездке: кто платил, за кого, чем (карта / Apple Pay / нал), на что — и итог «кто кому
сколько должен» в минимуме переводов. Расходы в любой валюте (THB, KZT, …), итог — в валюте поездки.

Стек: Vite + React + TypeScript + Tailwind, Supabase (Postgres + Auth + Realtime), хостинг Vercel. Всё бесплатно.

## Запуск локально

Нужен запущенный Docker Desktop — локальный Supabase (Postgres + Auth + Realtime) поднимается в контейнерах,
миграция применяется автоматически, подтверждение email выключено.

```bash
npm install
npm run db:start       # локальный Supabase; Studio: http://127.0.0.1:54323
npm run dev -- --port 5179
npm test               # тесты расчёта долгов
npm run db:reset       # очистить базу и заново применить миграцию
npm run db:stop
```

`.env.local` с локальными ключами (стандартные демо-ключи Supabase CLI):
`VITE_SUPABASE_URL=http://127.0.0.1:54321` и `VITE_SUPABASE_ANON_KEY` из вывода `npx supabase status`.

## Деплой (один раз, ~10 минут)

### 1. Supabase — база и регистрация

1. https://supabase.com → **New project** (регион ближе к вам, например Singapore).
2. **SQL Editor** → New query → вставить весь `supabase/migrations/0001_init.sql` → **Run**. Затем так же по порядку
   остальные файлы из `supabase/migrations/` (`0002_author_only.sql` и т.д.). Новые миграции на уже работающей базе
   выполняются тем же способом.
3. **Authentication → Sign In / Providers → Email**: **обязательно выключить Confirm email**. Вход в приложении по
   логину и паролю, а для Supabase логин превращается в служебный адрес `логин@trip.local`, на который письма не
   доходят.
4. **Project Settings → API**: скопировать `Project URL` и `anon public` key.

### 2. Vercel — хостинг

1. Залить репозиторий на GitHub.
2. https://vercel.com → **Add New → Project** → импортировать репозиторий (Framework: Vite определится сам).
3. **Environment Variables**: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` → **Deploy**.

Каждый `git push` в main — автоматический деплой.

### 3. На телефон

- **iPhone**: открыть сайт в Safari → «Поделиться» → «На экран Домой».
- **Android**: Chrome предложит «Установить приложение» (или ⋮ → Установить).

## Как пользоваться

1. Создай поездку → «Поездка» → «Поделиться ссылкой» → кинь в чат.
2. Друзья открывают ссылку, регистрируются (имя, логин, пароль) и попадают в поездку.
3. Кто платит — жмёт «+»: сумма и валюта, на что, чем платил, за кого (поровну или свои суммы).
4. «Итоги» — кто кому сколько переводит. После перевода — «Вернул ✓».
5. «Наличные» — личный кошелёк: «Привёз с собой» и «Обменял» (отдал 300 $ → получил 10 050 ฿). Расходы
   наличными и возвраты долгов наличными списываются сами — видно, сколько бат осталось на руках.

## Устройство

- `supabase/migrations/0001_init.sql` — таблицы, RLS (данные поездки видят только её участники), RPC `save_expense`
  (расход + доли атомарно, с проверкой суммы) и `join_trip`.
- `src/lib/balance.ts` — расчёт балансов и упрощение долгов (покрыто тестами).
- Суммы хранятся целыми числами в сотых долях; курс фиксируется в расходе на дату траты
  ([fawazahmed0/exchange-api](https://github.com/fawazahmed0/exchange-api)), его можно поправить вручную.
- `npm run icons` — перегенерировать иконки PWA.
